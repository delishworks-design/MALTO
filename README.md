# MALTO Cleaning Services

A Better Standard of Clean.

## Stack
- Next.js App Router
- React
- TypeScript
- Lucide-ready dependency
- Responsive CSS
- No external font or stock-image dependency

## Run
npm install
npm run dev

## Production
npm run build
npm start

## Deployment
This project is ready for a standard Next.js deployment such as Vercel or any Node.js host supporting Next.js.

## Important first-version limitation
The booking flow is a front-end request experience. There is no backend database, automatic email processing, Messenger integration, CRM, payment system, or payroll system in this first version.

The admin area is a planning/front-end structure and does not persist live data.

Customer-facing pricing does not expose internal labor, transport, materials, overhead, profit, or minimum-price rules.
